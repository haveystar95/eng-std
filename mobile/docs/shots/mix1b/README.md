# MIX-1b — голос идёт за карточкой

Баг с телефона владельца: в смешанной тренировке карточка итальянской коллекции читалась
английским голосом. Язык брался у СЕССИИ, а у кросс-коллекционной сессии его нет — падало на
профиль. Исправлено: локаль TTS/STT резолвится из пары коллекции КАРТОЧКИ (`_langOfCard` →
`ttsLocaleFor`), как это давно делает переводчик (A-3).

Пиннинг в коде: `test/features/training/tts_locale_follows_pair_test.dart` (что прозвучало и в
каком голосе — на method-channel `flutter_tts`) и `test/data/tts_locale_test.dart` (резолвер).

## Что осталось подтвердить ушами

Тесты доказывают, какую локаль приложение просит у движка. Чего они не доказывают — что iOS отдал
за неё НУЖНЫЙ голос: голосовой пакет языка может быть не установлен, и тогда система молча читает
дефолтным голосом (это ожидаемая деградация, факт уходит в лог строкой `[tts] no installed voice`).

Прогон, который это закрывает:

1. Билд — канонической командой из `mobile/CLAUDE.md` (`flutter run --release -d <iPhone>`).
2. Тренировка с главного экрана (НЕ «тренировка по теме» — нужна кросс-коллекционная сессия, где
   пул мешает языки). Что сессия смешанная, видно по бейджу пары («IT→RU» / «EN→RU») над карточкой:
   в смешанной он рисуется НА каждой карточке, в одноязычной — один раз в шапке.
3. Слушать переход между карточками разных пар. Ожидание: голос меняется вместе с бейджем.
4. Сюда — запись экрана со звуком или скрины (карточка + её бейдж пары).

Если голос на каком-то языке остался «английским с акцентом» — это не этот баг, а отсутствующий
голосовой пакет: Настройки → Универсальный доступ → Устный контент → Голоса.
