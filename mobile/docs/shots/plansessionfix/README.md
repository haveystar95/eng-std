# PLAN-SESSION-FIX — итоговый экран с раздельным счётом

`day-summary-split.png` — «День 1 пройден» после наряда, снят на симуляторе iPhone 17 (iOS 26.5)
с харнесса `tool/plan_summary_preview.dart`:

```bash
cd mobile && PATH="/opt/homebrew/bin:$PATH" LANG=en_US.UTF-8 flutter run --debug -d <simulator-udid> --target tool/plan_summary_preview.dart
```

Харнесс рендерит НАСТОЯЩИЙ `PlanDaySummary` на мок-данных: сессия из восьми карточек, из них шесть
принадлежат дню (пять разных терминов) и две — доливка из обычной очереди.

## Что на нём видно

| строка | значение | почему так |
|---|---|---|
| «5 фраз и слов в работе» | **день** | до наряда сюда попадали и карточки доливки: на живом дне из 14 карточек экран объявлял «21 фраза и слово» |
| «Ступень A пройдена · 2 слова · 3 фразы» | день, по типам | считается по тем же терминам дня |
| «Повторение · 2 слова» | **доливка** | отдельная строка; в счёт дня не входит |

Шов клиент берёт с сервера (`day_task_count` + `section` у каждой задачи), а не выводит эвристикой —
именно эвристика и ошибалась.

## Чего на скрине нет

Черты «— ПОВТОРЕНИЕ —» внутри самой сессии (Ч.2.2): она рисуется на первой карточке за границей
дня, то есть внутри тренажёра, а не на итоговом экране. Отдельного скрина по ней наряд не просил;
покрыта тестами `plan_session_seam_test.dart` и виджет-тестом итогового экрана.

## На устройстве

Снято на СИМУЛЯТОРЕ, не на телефоне владельца. Живой прогон этого экрана на реальных данных плана
«Отпуск в Италии» не делался — день 1 там уже пройден до наряда, и повторить сессию с доливкой
можно только на следующем дне.
