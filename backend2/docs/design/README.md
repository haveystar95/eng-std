# Дизайн-система «Слова» — финальный экспорт (фазы 1–2.14)

**Источник правды для Flutter-темы: `tokens.html`.**
При расхождении токен-листа с кадрами экранов побеждает токен-лист.

| Файл | Что внутри |
|---|---|
| `tokens.html` | Полный токен-лист: цвета (финальные), типографика Literata/Inter по ролям + раздел упражнений (2б), геометрия, паттерн плотности чернил, контекстное меню, мини-флаги, иконки Lucide, микроанимации базовые (4д) и упражнений (4е), ценовая карточка пейволла (4ж), тексты уведомлений (4з), **24 правила системы** |
| `phase2-screens.html` | Все утверждённые экраны 2.1–2.14: главная (2 состояния), триаж со свайпами, коллекция, редактирование, создание с голосом, состояния генерации, прогресс, пустые, стор, вход/онбординг/профиль, сессии упражнений (5 режимов + фидбек + итог), нотификации, пейволл, подписочные поверхности |
| `phase1-palettes.html` | История выбора палитры (7 направлений) — архив |
| `standalone-offline.html` | Автономный просмотрщик всех кадров (браузер, без сети) |

## Ключевые значения

paper `#F6F3EC` · ink `#2E2620` (тёплая умбра) · ink-body `#4A443D` ·
secondary `#6E6862` · tertiary `#8A857E` · surface-raised `#FCFAF5` ·
вердикты `#B5533C` / `#A6761F` / `#4E6B52` · деструктив текстом `#9A4430` ·
Literata — только целевой язык · Inter — весь UI · иконки Lucide ·
цены пейволла — плейсхолдеры, в коде только из StoreKit.
