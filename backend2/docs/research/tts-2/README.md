# TTS-2 — голос сервера на ElevenLabs, снос прежнего вендора голоса

Наряд TTS-2 (15.09.2026). Постановка — карточка архитектора; уточнение в ходе наряда (архитектор, 15.09): модель везде —
v3 Conversational, диалог одним вызовом не собирается, каждая реплика собеседника и ученика — отдельный вызов своим
голосом, нарезка и её прослушка не нужны и снесены, одновременность 3 (Starter), в учёт — точный id модели и
фактическая цена из заголовка ответа. Доработка того же дня: второй женский голос ученицы, голоса Дена, темп, кап покупок,
e2e-стенд вне автоозвучки (решения архитектора и владельца — Ч.1). Решение в реестре — DECISIONS п. 318; канон —
`docs/plan-v2.md` §7; контракт — `docs/plan-api.md` «Окно дня». Инструменты — `tools/` (`probe.php` — что вендор говорит о
себе, дубли и их распознавание; `day_voice.php` — голос каждой строки дня изнутри приложения).

Цифры денег везде в трёх единицах: **кредиты · символы · $** (Starter: $0,20 за 1 000 кредитов; у v3 Conversational
кредит — это четыре символа, вверх по строке).

## Ч.1 — что сделано

- **Порт синтеза** (Generation) — `speakLines` (строка — свой вызов, купленное отдаётся сразу), `creditsFor` (во что
  обойдутся строки до покупки: тариф модели за их символы по цене кредита, вверх по строке) и `balance`
  (`/v1/user/subscription`); одна реализация — ElevenLabs, двойник — только тесты и `SPEECH_DRIVER=fake`. Раунды через
  `Http::pool` по числу из заголовка вендора (конфиг на старте — 3).
- **Голоса по роли и полу** (Shared `VoiceRole`, `VoiceCatalog`): `voices.en.{partner,learner}.{female,male}` — четыре
  разных голоса, голоса ролей в сцене всегда разные; id — строки `.env` для лёгкой смены
  (`SPEECH_VOICE_EN_PARTNER_FEMALE`, `…_PARTNER_MALE`, `…_LEARNER_MALE`, `…_LEARNER_FEMALE`, умолчания те же в
  `config/generation.php`). Ключ файла — `elevenlabs:<модель>:<голос>:s50`. Реплика — отдельный вызов, связная интонация
  диалога сознательно не требуется (DECISIONS п. 318).
- **Всё, что звучит в дне**: реплики собеседника (`x3`) и ученика (`x3b`), фразы (`p2`), **фразы с наполнениями**
  (`p2.f3` — каркас с третьим наполнением; наполнение, которым сказана сама фраза, — её файл, второго вызова нет),
  слова (`v5`). GET дня — `audio_url` у каждого наполнения (аддитивно: `plan-api.md`, `openapi.yaml`).
- **Отказы**: 429 и 5xx — короткие повторы (1, 2, 4, 8 с), потом `VoiceSceneJob` уходит в очередь на 30 с и не падает;
  401/402/403 и коды отказа аккаунта при любом статусе — job `failed` с кодом вендора, письмо в лог (`Log::error`),
  окно дня читает голос телефона; отказ прочитать один текст — строка пропускается.
- **Учёт** (`plan_line_audios`): `characters` — символы текста, `credits` — `character-cost`, `cost_usd` — кредиты ×
  цена кредита тарифа (`generation.speech.usd_per_thousand_credits`, Starter $0.20), `request_id`. Команда
  `plan:speak-report {--plan=} {--day=}` — все планы / план по дням / день по видам строк: символы, $, кредиты, вызовы.
- **Предохранитель** (`VoiceFuse`): перед каждой сценой остаток кредитов по API аккаунта, если ответил, иначе по
  `plan_line_audios.credits` с начала месяца против `generation.speech.monthly_credits`; меньше 10 % — ничего не
  покупается, письмо в лог (job) или стоп с сообщением (бэкфилл).
- **Кап одного запуска покупок** (доработка, решение архитектора; `VoiceCap`, `SPEECH_JOB_CREDITS_CAP`, по умолчанию 3 000
  кредитов): задача сцены — запуск, бэкфилл — один запуск на все свои сцены. Перед каждой сценой купленное за запуск плюс
  оценка сцены не помещается под кап — сцена не покупается, стоп, письмо в лог.
- **e2e-стенд вне автоозвучки и бэкфилла навсегда** (доработка, решение архитектора;
  `generation.speech.named_plans_only_databases = ['wordtrainer_e2e_test']`): новый день там задачу голоса не ставит,
  `plan:speak-backfill` без `--plan` отказывает с кодом 1; голос — только по явному `--plan`.
- **Бэкфилл** `plan:speak-backfill {--plan=*} {--count} {--drop-unread} {--drop-only}` — сцена за сценой; порядок: планы учеников →
  планы QA-аккаунтов (симулятор), новые раньше; `--plan` — только названные; «не озвучено» по пяти видам до и после и что
  куплено; **`--count` называет цену недостающего — кредиты · символы · $ — её называют до покупки**; `--drop-unread`
  (доработка) — прямо перед покупкой сцены, после проверки капа, удаляет её строки и файлы под голосом, которого у
  говорящего больше нет; при выключенном голосе не удаляет ничего; `--drop-only` (доработка) — только удаляет такие строки и
  файлы, ничего не покупая.
- **Миграции**: `2026_09_15_200000` — `characters`, `credits`, `request_id`, `line_ref` с наполнениями (откат проверен
  на `wordtrainer_test`: fresh → rollback --step=2 → migrate); `200100` — голос прочих вендоров удалён (строки и файлы),
  односторонняя. На `wordtrainer` — plain `migrate` после бэкапа `wordtrainer-20260915-133034.sql.gz`: удалено 77 строк и
  77 файлов (1,17 МБ); на `wordtrainer_e2e_test` (бэкап `…-133039`) — 0. Доработка миграций не добавляет.
- **Лог исходящих** — тег `elevenlabs`; ключ в `xi-api-key` скрывается общим правилом.

## Ч.6 — не проверено и открытые вопросы

- **Строки ученика без серверного голоса**: план симулятора — 70 строк (2 дня), e2e — 153 строки (4 дня с учеником-мужчиной);
  замедленные файлы удалены без переозвучки, эти строки звучат голосом телефона. Озвучить — только по команде, с ценой из
  `--count`.
- **Кап — только Pest**: живьём ни один запуск до 3 000 кредитов не дошёл. Кап — на запуск (решение архитектора: этого
  достаточно вместе с правилом «покупки только по команде»); два запуска подряд — два капа.
- **Симулятор после смены голосов не открывался**: день Дена проверен GET дня и отдачей файлов.
- **Оценка `--count` выше счёта вендора** на несколько процентов (338 против 324 кредитов на тех же 40 строках) — цена
  называется с запасом.
- **Телефон Дена** — сборка не нужна (клиент не менялся); план Дена на телефоне не открывался.
- **Образ** не пересобирался: кодировщик убран из `Dockerfile`.
- **Счёт вендора запаздывает**: `/v1/user/subscription` сразу после покупки показывает прежний остаток (выравнивается за
  секунды) — предохранитель на границе 10 % может пропустить одну сцену.
- **Цена кредита** — конфиг тарифа (Starter $0.20). При смене тарифа менять `SPEECH_USD_PER_THOUSAND_CREDITS`.
- **Новые уроки озвучиваются сами** (`SPEECH_ENABLED=true`): день ≈ 230–500 кредитов; предохранитель остановит на 10 %, кап —
  на 3 000 за запуск.
- Канон теста «диалог сцены = один вызов, две роли» из постановки заменён уточнением — «каждая реплика — отдельный вызов
  своим голосом»; связная интонация диалога сознательно не требуется (DECISIONS п. 318).
