# TTS-2 — голос сервера на ElevenLabs, снос прежнего вендора голоса

Наряд TTS-2 (15.09.2026). Постановка — карточка архитектора; уточнение в ходе наряда (архитектор, 15.09): модель везде —
v3 Conversational, диалог одним вызовом не собирается, каждая реплика собеседника и ученика — отдельный вызов своим
голосом, нарезка и её прослушка не нужны и снесены, одновременность 3 (Starter), в учёт — точный id модели и
фактическая цена из заголовка ответа. Решение в реестре — DECISIONS п. 318; канон — `docs/plan-v2.md` §7; контракт —
`docs/plan-api.md` «Окно дня». Инструменты — `tools/` (`probe.php` — что вендор говорит о себе, `day_voice.php` — голос
каждой строки дня изнутри приложения).

## Ч.1 — что сделано

- **Порт синтеза** (Generation) — `speakLines` (строка — свой вызов, купленное отдаётся сразу) и `balance`
  (`/v1/user/subscription`); одна реализация — ElevenLabs, двойник — только тесты и `SPEECH_DRIVER=fake`. Раунды
  через `Http::pool` по числу из заголовка вендора (конфиг на старте — 3).
- **Голоса по роли и полу** (Shared `VoiceRole`, `VoiceCatalog`): `voices.en.{partner,learner}.{female,male}` —
  собеседник-женщина `4tRn1lSkEn13EVTuqb0g`, ученик-мужчина `TWutjvRaJqAX89preB4e`, собеседник-мужчина
  `EnjklPXGBMNldCJ7jqkE`, ученик-женщина — тот же женский голос. Ключ файла — `elevenlabs:<модель>:<голос>:s50`.
- **Всё, что звучит в дне**: реплики собеседника (`x3`) и ученика (`x3b`), фразы (`p2`), **фразы с наполнениями**
  (`p2.f3` — каркас с третьим наполнением; наполнение, которым сказана сама фраза, — её файл, второго вызова нет),
  слова (`v5`). GET дня — `audio_url` у каждого наполнения (аддитивно: `plan-api.md`, `openapi.yaml`).
- **Отказы**: 429 и 5xx — короткие повторы (1, 2, 4, 8 с), потом `VoiceSceneJob` уходит в очередь на 30 с и не падает;
  401/402/403 и коды отказа аккаунта при любом статусе — job `failed` с кодом вендора, письмо в лог (`Log::error`),
  окно дня читает голос телефона; отказ прочитать один текст — строка пропускается.
- **Учёт** (`plan_line_audios`): `characters` — символы текста, `credits` — `character-cost`, `cost_usd` — кредиты ×
  цена кредита тарифа (`generation.speech.usd_per_thousand_credits`, Starter $0.20 = $6 за 30 000; у v3 Conversational
  это ровно $0.05 за 1 000 символов, расхождение — только округление вендора вверх), `request_id`. Команда
  `plan:speak-report {--plan=} {--day=}` — все планы / план по дням / день по видам строк: символы, $, кредиты, вызовы.
- **Предохранитель** (`VoiceFuse`): перед каждой сценой остаток кредитов по API аккаунта, если ответил, иначе по
  `plan_line_audios.credits` с начала месяца против `generation.speech.monthly_credits`; меньше 10 % — ничего не
  покупается, письмо в лог (job) или стоп с сообщением (бэкфилл).
- **Бэкфилл** `plan:speak-backfill {--plan=*} {--count}` — сцена за сценой; порядок: планы учеников → планы QA-аккаунтов
  (симулятор), новые раньше; `--plan` — только названные, в названном порядке; «не озвучено» по пяти видам до и после и
  что куплено (строки, символы, $, кредиты, вызовы).
- **Миграции**: `2026_09_15_200000` — `characters`, `credits`, `request_id`, `line_ref` с наполнениями (откат проверен
  на `wordtrainer_test`: fresh → rollback --step=2 → migrate); `200100` — голос прочих вендоров удалён (строки и файлы),
  односторонняя. На `wordtrainer` — plain `migrate` после бэкапа `wordtrainer-20260915-133034.sql.gz`: удалено 77 строк и
  77 файлов (1,17 МБ); на `wordtrainer_e2e_test` (бэкап `…-133039`) — 0.
- **Лог исходящих** — тег `elevenlabs`; ключ в `xi-api-key` скрывается общим правилом.

## Ч.6 — не проверено и открытые вопросы

- **Телефон Дена** — сборка не нужна (клиент не менялся); план Дена на телефоне не открывался.
- **Мужской голос собеседника** подобран по описанию, ушами не слушан. Живьём он звучит в двух днях GEN-2a с
  мужчиной-собеседником («Заказ в ресторане», «Просмотр жилья»): 8 реплик собеседника голосом `Enjk…`, 37 строк ученика —
  женским `4tRn…`; остальные 7 сцен — собеседник-женщина.
- **Образ** не пересобирался: кодировщик убран из `Dockerfile`, в работающем контейнере он есть и не используется.
- **Счёт вендора запаздывает**: `/v1/user/subscription` сразу после покупки показывает прежний остаток (выравнивается за
  секунды) — предохранитель на границе 10 % может пропустить одну сцену.
- **Цена кредита** — конфиг тарифа (Starter $0.20). При смене тарифа менять `SPEECH_USD_PER_THOUSAND_CREDITS`; кредиты в
  строках от этого не меняются.
- **Новые уроки озвучиваются сами** (`SPEECH_ENABLED=true`): день ≈ 400–500 кредитов, предохранитель остановит на 10 %.
- **Вопрос архитектору**: канон теста «диалог сцены = один вызов, две роли» из постановки заменён уточнением — «каждая
  реплика — отдельный вызов своим голосом»; интонация ответа на вопрос между репликами теперь не связана.
