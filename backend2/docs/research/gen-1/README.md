## Ч.2 — канон качества (против него судим)

Правила из наряда, дословно. У каждого — где оно должно держаться: **промпт И судья** либо
**валидатор кода**; на «повезло» не держится ничего.

### Реплики `you` («Ты ответишь» / «Ты спросишь»)

| # | правило | держится |
|---|---|---|
| Y1 | ответ ПРЯМО на реплику роли перед ней (пара) | промпт P2 + судья P2J |
| Y2 | полка «ты ответишь» — только ответы; переспросы/уточнения («Sorry, do you mean…») — НЕ ответы, в эту полку не попадают | промпт P2 + судья P2J (вопрос «не переспрос?») + валидатор отбрасывает пару по вердикту судьи |
| Y3 | уровень basic: 4–8 слов, разговорно, без канцелярита; intermediate: до 12 слов; судья спрашивает «сказал бы так человек этого уровня?» | промпт P2 + судья P2J (вопрос «простота уровня»); длина — валидатор (`card.kind_size`) |
| Y4 | у каждой реплики 1–2 допустимых упрощённых варианта ключа (`speaking_keys[]`), засчитывается любой | промпт P2 + схема + валидатор «непустые» + грейдер |
| Y5 | слова и связки дня — те, что реально стоят в репликах сцены; слово, которого нет ни в одной реплике, в день не попадает | валидатор кода (отбросить карточку) |

### Реплики роли (`hear`)

| # | правило | держится |
|---|---|---|
| H1 | естественный вопрос или приглашение | промпт P2 + судья P2J |
| H2 | для `ask`-пары — приглашение («Anything you'd like to ask?»), не вопрос | промпт P2 + судья P2J |

### Перевод

| # | правило | держится |
|---|---|---|
| T1 | ровно смысл фразы, без добавок из контекста сцены и без пропусков | промпт P2 + судья P2J (вопрос «перевод точный?») |

### Сцена

| # | правило | держится |
|---|---|---|
| S1 | 4–6 пар | промпт P2 + валидатор (`day.pairs_too_few` < 4) |
| S2 | один связный разговор, не список несвязанных вопросов | промпт P2 (+ глазами в прогоне) |
| S3 | роль названа | промпт P1 (вводка) |
| S4 | название сцены — про ситуацию, не про грамматику | промпт P1 |

### План

| # | правило | держится |
|---|---|---|
| P1 | число дней = дни до события (потолки из `plan-model.md`) | `PlanScheduler` (код) — день = сцена, лишние режутся с конца |
| P2 | сцены не повторяют друг друга по теме | промпт P1 (+ глазами) |

### Как считаем в прогоне (Ч.3 и Ч.6)

На каждую пару — пять вопросов, отвечает человек (сессия), не судья:

1. **ответ на вопрос?** — `you` отвечает именно на `role` этой пары (Y1);
2. **простота?** — сказал бы так человек уровня basic: 4–8 слов, без канцелярита (Y3);
3. **перевод точный?** — у обеих реплик пары, без добавок и пропусков (T1);
4. **переспрос в ответах?** — `you` пары `answer` не является переспросом/уточнением (Y2; «да»
   = нарушение);
5. **слово без реплики?** — считается по дню: каждое слово/связка стоит хотя бы в одной реплике
   сцены (Y5; считается на карточку, не на пару).

Плюс по сцене: S1 (число пар), H2 (role у `ask` — приглашение), S2 (связность, да/нет), и по
плану: P1 и P2.
