## §1. Что сделано по кадрам

### 1.1. Окно повторения и репетиции (37-1, 37-2)

«Второй компонент окна: то же окно дня 23-0a, сменились ряды и список под плитой» (подпись 37-2). Сделано так:

| что | как |
|---|---|
| плита | та же `WindowPlate`, режим «системный день»: бровь — вид дня («РЕПЕТИЦИЯ» / «ПОВТОРЕНИЕ»), заголовок — имя плана у репетиции («Приём у врача»), «Что уже было» у повторения; строка состояния; одна фраза о дне («Проговоришь весь разговор с собеседником» / «Вернёшь фразы прошлых дней и поговоришь с собеседником»); ряды — ровно `window.stages`; низ плиты 28 (пилюли нет) |
| строка состояния | репетиция: «перед событием · когда · состояние · минуты»; повторение: «состояние · минуты». «Когда» — `slot.label_native` у «сегодня» / «завтра», иначе день недели даты слота («в четверг»); минуты — `minutes_estimate` до старта («около 12 минут»), `minutes_spent` у пройденного («21 минута»), у идущего — ни одной (своё говорит текущий ряд) |
| под плитой | «ИЗ КАКИХ СЦЕН» / «ИЗ КАКИХ ДНЕЙ» и карточки 72: фото 48 сцены на её тоне, имя 15/20 (переносится — ничего не режется), справа «N реплик» — только когда число есть у сервера |
| вкладки программы | нет: список дней и сцен — и есть программа этих дней (пилюли и компактной шапки нет, статус-бар темнеет, когда плита уезжает под него) |
| кнопка | одна, по `allowed_action` (у пройденной репетиции сервер действия не даёт — кнопки нет, §2) |

**Откуда список.** У блока `window` списка сцен и дней нет, поэтому он читается из того, что в ответе дня есть
(`WindowSources`):
- розданный день — по его карточкам: обзор репетиции `recall_scenes` называет каждую сцену с её репликами (число «N
  реплик» — длина списка сервера); карточки повторения называют сцены, из которых розданы (`payload.scene_id`), и дни
  маршрута этих сцен — «дни, откуда»;
- нерозданный — по правилу, по которому раздаёт сервер: репетиция — готовые сцены плана по порядку, повторение — два
  дня-сцены перед ним. Чисел там нет: считать ещё нечего.

«N карточек» кадра 37-2 не печатается — поле не приходит, карточки клиент не считает (§5).

### 1.2. «Вспомнить»: обзор 37-3 → 35-4 × N → итог 37-4

- **Новый вид `recall_scenes`** (`SessionKind.recallScenes`, конверт `recall`, запись `passed` — прохождение):
  `RecallScenesPayload` — сцены плана с их СВОИМИ репликами (текст, перевод, звук). 28 видов раздаются, экраны есть у
  всех (контракт-тест: фикстуры вместе несут каждый вид).
- **Обзор 37-3** (`RecallScenesCard`): «Вспомни свои реплики», страница на сцену, реплика Literata 22 + перевод +
  «прослушать» 44 (латунный круг; пока реплика звучит — латунная волна из девяти полос кадра, шире круга, как в кадре);
  волосяные линии между репликами; точки страниц; листается свайпом и «Дальше», на последней — «Дальше — повтори
  вслух», и этот тап — единственный ответ карточки. Ничего не проверяется.
- **Шапка обзора** — «≈ N мин» этапа из окна (`minutes_left`), бусин нет; счёта «ещё N реплик» у обзора нет — это не
  реплика.
- **Полоса сцены идёт за страницей**: у репетиции и повторения своей сцены нет, поэтому полоса называет сцену
  карточки (`sceneOfCard`), а обзор — сцену на экране (`CardEnv.showScene`).
- **35-4 × N** — прежний экран; шапка «ещё 9 реплик» … «ещё 1 реплика» (37-4: «меняется только шапка»).
- **Итог 37-4** — 30-6 «Вспомнил · около 6 минут» и «Дальше», строки «закрыто / вернётся» нет: у обзора нечего
  закрывать, а у последнего дня плана нечему возвращаться.

## §5. Чего сервер не даёт (handoff бэкенду)

1. **Списка сцен / дней у окна повторения и репетиции нет** — клиент читает его из карточек дня или по правилу
   раздачи; «N карточек» 37-2 не приходит. Дать `window.sources[]` (`scene_id` / `day`, имя, фото, число).
2. **Минуты рядов нераскрытого дня** — 37-1/37-2 печатают «около N минут» у каждого ряда, `minutes_left` приходит
   только текущему. Дать оценку каждому ряду.
3. **Имена сцен расходятся**: обзор `recall_scenes` называет вторую сцену «У врача с сыном», план — «Приём у врача»
   (полоса, дни маршрута). Одно имя на сцену.
4. **`minutes_spent` дня до закрытия не включает разговор**: 30-7 печатал «6 минут», закрытый день — 9.
5. **У пройденной репетиции нет действия** — кадр рисует «Повторить разговор».
6. Число сцен до старта репетиции (37-5) — закрыто CONV-2 (`scenes_count` в ряду окна), клиент — окно 1c.
