### §1 replayAccepted — клиент не строже сервера на повторе

- **Повтор `speak_answer`** («Ещё раз», судьи нет — сервер отказал бы `plan_card_answered`) судит телефон, и судит
  ТОЛЬКО тем, чем сервер отказывает кодом: `SessionRules.answerRefusedByCode` — зеркало кодовых отказов SlotJudge:
  1. не услышано ни слова → отказ («Не расслышал»);
  2. у каркаса с окном и подсказкой: ни одно значение окна не прозвучало, а сверх каркаса — только служебные слова →
     отказ («Не сказал главного»).
  «Сверх каркаса» считается по СКАЗАННЫМ словам, как в серверном `SpeechMatch::slotWords`: сказанное слово
  засчитывается каркасу, только если все его нормализованные части ещё свободны, иначе оно целиком — «сверх»
  (`SpeechMatch.beyondKey`; поправлено по ревью инвариантов, §7: счёт по нормализованным словам на «the
  over-the-counter» оставлял «the» и отказывал там, где сервер спрашивает модель).
  Всё остальное сервер отдаёт модели, которой у телефона нет, — телефон зачитывает. Список служебных у телефона —
  `speech.articles` пакета дня (подмножество серверных `function_words`), поэтому телефон на кромке **мягче** сервера
  («OK I will return» проходит), но никогда не строже.
- Своё слово «Скажи целиком» (32-7) на повторе — каркас сказан, слово любое (как сервер: «Каркас не прозвучал» кодом);
  остальные голосовые виды — прежнее покрытие строки (FIX-1 §5, «не пропускать любой звук»).
- `SessionRules.expectedSpeech(speak_answer)` — своя реплика целиком (со значением окна), а не голый каркас: голый
  каркас сервер отказывает кодом.
- На живом проходе вердикт — всегда ответ судьи; локальная раскраска живой строки (шалфей по совпавшим словам) —
  только подсветка, не вердикт.
- Тесты на канон: `session_rules_test` «a replay of «Ответь своими словами» refuses only what the server refuses by
  code» (что сервер зачёл — зачитывает и телефон; что отказал кодом — отказывает и телефон), `session_queue_test`
  «Once more…» (повтор судится телефоном, но не пропускает пустое).
