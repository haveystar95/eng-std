## §1. Итог

  `word_assemble` по индексу слова от старта по зерну сцены; вид, который слову не подходит, **меняется с ближайшим словом**,
  которому подходит (решение архитектора, §2); обменяться не с кем — следующий подходящий по кругу; вид без материала
  выпадает. Привилегии сборки больше нет.
- **Живой «врач»**: было 6 сборок, 1 `word_in_line`, 1 `word_choose` и ни одного «на слух» — стало **по две проверки каждого
  вида**; то же на чистом уроке, и на обоих — **при любом из четырёх стартов круга** (§4).
- **`word_choose` — в обе стороны у любого уровня**, направления чередуются по выборам дня; этап «Слова» один на оба
  уровня (тест сравнивает день beginner и intermediate карточка в карточку). Каталожный добор переводов — у любого уровня.
- **`word_listen` — звук → перевод**: варианты на родном, верный — перевод слова, `direction: term_to_native`, текста цели
  на карточке нет (§5).
- **`phrase_combine` — только на вопрос собеседника**, первый по визиту; нет вопроса — карточки нет (и в возврате); у каждого
  каркаса `said` — целая фраза (§6).

## §7. Наполнения с «нет» судьи швов (п. 4)

**Правило в коде**: `PlanScene::unreadableFillers()` — адреса находок `filler.native_seam`; `DayDealer` кладёт их в

(`PhraseSeries::fillers/most`), `phrase_repeat`, `phrase_other_slot` (и выбор «варьируемого» каркаса `PhrasesStage`), копии и
возвраты, ложные варианты `phrase_slot`/`phrase_slot_listen`/`phrase_choose_back`, чипы и `frame.slot.fillers` всех карточек,
`examples`; значения `listen_number` — тем же `hides`. Судья не зовётся: находки уже в сцене.
