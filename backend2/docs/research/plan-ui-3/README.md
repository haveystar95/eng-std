## 0. Решения владельца на старте (12.09, в этой сессии)

Наряд опирался на то, чего в сервере PLAN-GEN нет. Вопросы заданы до кода, ответы:

1. **Этапы на линии — пять, как на сервере.** Канва рисует три («Слова и фразы / Разговор / Скажи
   сам») + «Повторить ошибки»; сервер отдаёт пять (`words, phrases, dialogue, listen, speak`).
   Решено: `days[].stages` — пять этапов сервера с `done/current/locked`, у повторения и репетиции —
   сколько отдал сервер; «Повторить ошибки» убран из наряда (функции нет); плита — те же пять строк,
   состояние словами; текст правила «Пять этапов по порядку…» остаётся. **Канва на этот пункт
   временно не эталон** — шаг 44, заливка и три состояния дня взяты из кадров.
2. **Push без entitlement.** Бесплатная Personal Team не даёт Push capability; регистрация токена
   падает тихо в лог; напоминание, «ждёт со вчера», «сегодня событие» телефон ставит локально по
   датам плана; «план готов / день собран» — баннер в приложении при возврате.
3. **`plan.summary` без модели и без промпта**: первые три сцены строчными + «К <дате> скажешь всё
   это сам»; plan-builder-v3 не заводился, фикстуры под промпт не пересобирались.
4. (В ходе) **Список языков плана — сервер**: `GET /plans/languages` (`PLAN_LANGUAGES`, сегодня en, de).

Имена из старой цепочки в наряде (`learning_plan_events`, `PlanDayPassing`, «P1-каркас», `day_state`)
переведены на текущий модуль `Plan`: `plan_events`, `CloseDayHandler`, `summary` в ресурсе, `stages`.

## 9. Уведомления: как доставляются сейчас и после ключа

| Уведомление | Сейчас (нет `APNS_KEY_P8`, нет entitlement) | После ключа .p8 и Push capability |
|---|---|---|
| план готов | журнал `plan_ready`; письмо в лог + `not_sent`; в приложении — баннер 22-6 при возврате | APNs на токены ученика; баннер остаётся для открытого приложения |
| день N собран (N ≥ 2) | журнал `day_ready`; лог + `not_sent`; баннер при возврате | APNs |
| ежедневное напоминание (час обычного захода, ≤ 1 в сутки) | **локально** на телефоне на неделю вперёд, пересчёт при каждом открытии и смене маршрута; сервер — тик 15 мин → лог + `not_sent` | APNs с сервера; локальное напоминание нужно будет снять (иначе два) — вопрос §11 |
| сегодня разговор — скажи сам | **локально** в дату события вместо напоминания; сервер — тик с 08:00 → лог + `not_sent` | APNs |
| дни пропущены | **локально**: наутро после даты дня, который не пройден, — «День N ждёт со вчера / Маршрут сдвинулся…»; сервер пропусков не видит, пишет `days_skipped_rebuilt` только при укорачивании маршрута (`PATCH /schedule`) → лог + `not_sent` | APNs на укорачивание; детекция пропусков на сервере — отдельный наряд |

Тап по локальному уведомлению и по баннеру открывает таб «План» и прокручивает маршрут к дню.

## 11. Что не проверено живьём и открытые вопросы

**Не проверено живьём:** APNs (нет ключа .p8 и entitlement — отправка проверена `Http::fake`, JWT
проверен openssl); печать голосом (нет микрофона на симуляторе — тест со сценарным распознавателем);
баннер «день собран» при возврате; локальные уведомления в момент срабатывания (поставлены — лог
`scheduled 6`, но до их времени прогон не дожил); сборка на телефоне не открывалась руками.

**Вопросы архитектору / владельцу:**
1. Канва PLAN-DES-3 рисует три этапа — перерисовать кадры под пять (решение 12.09).
2. «Ко 2 сентября»: шаблон даёт «К 2 сентября» — оставить?
3. `event_today` на сервере не раньше 08:00; локально — в час обычного захода. Свести к одному?
4. Когда появится ключ — как клиенту узнать, что сервер начал слать push, и снять локальные напоминания?
5. Детекция пропущенных дней на сервере (сейчас только локальное «ждёт со вчера»).
6. Картинки делят троттл API 120/мин — вынести `/plans/images/*` из троттла?
7. Отклонения от кадров, оставленные сознательно: минуты («≈ 20 мин») контракт не отдаёт — в мете
   сегодняшнего дня число карточек; в примерах витрины фото нет (статический конфиг); флаги в

### Д3. Картинки вне лимита API — nginx отдаёт статику

- Новый сервис compose `web` (`nginx:1.27-alpine`, `wt_web`, конфиг `docker/nginx/default.conf`).

  /plan-images/$scene/$size.jpg @laravel` (том `storage/app/private/plan-images`, read-only),
  `Cache-Control: public, max-age=31536000, immutable`, ETag. Нет копии на диске — в Laravel
  (самолечение), который её скачает и положит; следующий запрос уже статика.
- В Laravel маршрут картинок вынесен из группы `throttle:120,1` (только `auth:sanctum`) — на

  `X-RateLimit-*`, у маршрута нет throttle-мидлвара, у `plans/versions` — `throttle:120,1` есть.
