## Ч.1 — DAY-UI-2 → DAY-UI-3: что остаётся, что меняется, что сносится (список ДО правок)

**Остаётся.**
- Сервер: блок `window` и его правила (`WindowStatus`, `DayWindowStages`, `DayPace`, `UnitStates`,
  `ProgramSummary`, `WindowAction`), `day_progress`, тона слотов (`ImageTones`), таблица
  `plan_line_audios` с ключом `line_ref`, `GET /plans/audio/{id}`, команды `plan:images-backfill` и
  `plan:speak-backfill` (внутри переписываются).
- Клиент: `DayWindowScreen` — одна дверь (`openDayRoom`, ссылка), `dayRoomProvider` с `autoDispose`,
  закрытый разбор `DayWindow.fromJson`, одна кнопка `WindowActionBar` с градиентом 24, `WindowTexts`
  (статус, бровь, действие), ряд этапа `WindowStageRow`, компактная шапка 56, `WindowPhoto`
  (тон → фото 200 мс), `ImageLoader`, «Ещё раз» = «Говорю сам» без записи, галка этапа через 300 мс.

**Меняется.**
- Плита: название 44/48 → **30/36 в одну строку (26 при переносе)**; список целей с кружками →
  **одно предложение** «Научишься …» / у пройденного «Научился: …» шалфеем с галкой 14; лейбл
  «НАУЧИШЬСЯ» уходит; стрелка и бровь «ДЕНЬ N» — одна строка 24; ряды этапов 48; «День пройден · N минут»
  встаёт на место статуса (подвал под этапами уходит); тень `0 8 24 .18`; низ плиты 48 (заход пилюли 24
  + воздух 24).
- Вкладки: текстовые 44 с латунной чертой и хайрлайном → **пилюля-сегмент 48 на шве** (перекрытие 24),
  значок + слово, активный — чип чернила, скользит 220 мс; прилипает под компактной шапкой со своей
  постоянной тенью.
- Прокрутка: сжатие плиты `AnimationController`'ом (240 мс по порогам 85 % / 60 %) плюс доводка
  `animateTo` 240 — две анимации одной вещи → **плита и шапка — функция позиции прокрутки 0…160 px**
  и один `animateTo` 260 мс ease-out-cubic при отпускании.
- Слова: фото 96 + Literata 17 + перевод → **фото 4:3, слово 22, чтение 13, перевод 15, «прослушать» 28**;
  тап → **шит 23-0e**.
- Фразы: текст + перевод + «прослушать» голосом телефона → **текст, чтение, перевод, «прослушать» 28
  голосом сервера**. Диалог: «прослушать» только у собеседника → **у обеих реплик**, маркер — у своей.
- Контракт `window`: слову — `pronunciation`, `definition`, `audio_url`, `usage {text, translation,
  offset, length, audio_url}`, `returns_day`; фразе — `pronunciation`, `audio_url`; реплике ученика —
  `audio_url`.
- Голос: один голос, реплика собеседника — вызов на реплику → **два голоса на сцену** (расстановка по
  `role_gender`, по умолчанию собеседник женский / ученик мужской); **диалог — один вызов с двумя
  говорящими, разрезанный по паузам**; фразы и слова пачками; **≤ 4 вызовов на день**; 429 поминутный и
  суточный различаются — job ждёт следующего окна.
- Фото: job плана после каждого урока, последовательно, ступени `image_prompt` → голое слово → название
  сцены, день `ready` раньше фото → **job сцены сразу после урока: фото сцены и всех слов параллельно
  (пул 6), с повторами**; ступени `image_prompt` → «термин, тема сцены» → тема сцены (своё фото на
  слово); **`ready` ждёт фото** (внутри `illustrating`, на проводе — `building`).
- Урок: `lesson-v3` → `lesson-v4` (+ `role_gender`).
- Звук на телефоне: `LineAudioCache` качает сам → общий **`AudioLoader`** (6 параллельно, диск, повторы),
  как `ImageLoader`; окно при открытии качает все фото и весь звук дня.

**Сносится.**
- Клиент: текстовые вкладки `WindowTabBar` с чертой и `AppMotion.windowTabsSnap`; делегат `_Header` с
  `FadeTransition` по контроллеру, `_collapse` и пороги `_collapseAt/_expandAt`; `CabIn` (`om-cab-in`) и
  `AppMotion.windowTabContent*`; список целей `_GoalRow` и ключ `planWindowGoalsLabel`; подвал итога под
  этапами; сетка `_WordCard` с фото 96; правило «фразы голосом телефона» (`_listen(partner: false)`);
  `WindowPlate.overlap`.
- Сервер: `RoleLineQueue`, покупка «реплика за вызовом» в `SpeakSceneLinesHandler` / `SpeakSceneLinesJob`;
  ступень «голое слово» в `ImageQueries`; часть «слова» в `AttachPlanImagesHandler` (переезжает в job
  сцены); оговорка «у фраз нет голоса сервера» в `DayWindowViews`, `WindowPhraseView`, `WindowLineView`.
