## Не переигрывать молча (решения)

- **`legacy` сентинелом, а не NULL-как-legacy.** После бэкфилла NULL невозможен у старой строки,
  поэтому появившийся NULL значит ровно одно: писатель создал контент и не проштамповал его.
  DEFAULT у колонки нет намеренно — иначе тот же баг снова прячется за правдоподобным значением.
- **Промпт — файлы, не таблица.** Промпт корректен только вместе с плейсхолдерами адаптера и
  JSON-схемой ответа, а они в коде. В таблице текст правится без диффа и ревью, и `prompt_version`
  на строке контента перестаёт что-либо доказывать. Остаток дыры закрывает sha256 в `RenderedPrompt`.
- **v10 составной, а не три файла.** Правило изоморфности одинаково во всех трёх формах; три файла =
  три копии правила, и расходится та, которую никто не перечитывает.
- **Песочница — отдельные ТАБЛИЦЫ, не отдельная схема.** Нужная изоляция («ни один читатель контента
  сюда не ходит») выполнена по построению; реальный риск снят тем, что порт журнала не имеет метода,
  которым можно записать контент. Тест это утверждает счётчиками до/после.
- **Нет ключа — не ошибка.** Провайдер помечается unavailable и называется в отчёте вместе с
  env-переменной, которая это чинит. Прогон едет по доступным.
- **Боевая генерация НЕ переключена** ни на v10, ни на другого провайдера.
- **`OpenAiCollectionGenerator` оставлен как есть.** Он обслуживает боевую генерацию; схлопнуть его в
  новый стек — правильный следующий шаг, но делать это посреди моратория значит переводить прод на
  код, который в проде ещё не работал.

## Найдено попутно — в работу НЕ бралось

- **9 терминов витрины имеют ДВА `is_primary` перевода** («stay calm» → «Оставайтесь спокойны» И
  «оставаться спокойным»; «get on» → «Ладить с кем-то» И «сесть (в транспорт)» — это уже два разных
  значения). Вопрос карточки тогда — тот перевод, который вернул запрос. Контент не трогал;
  выборка bake-off дедуплицируется по термину.
- **У команды xAI нет кредитов** — ключ валиден, 403 `permission-denied` на каждом вызове.
- **Anthropic-ключа нет** (у организации нет кредитов — известно из `CLAUDE.md`).
- **У OpenAI кончились кредиты** посреди второго прогона («You have no credits remaining»).
  Это блокер для повторного прогона, и он требует действия владельца, а не правки кода.
- **Лимит OpenAI 30000 токенов/мин** при промпте ~4.5k токенов — это ~6 вызовов в минуту. Прогон без
  пауз теряет треть вызовов в 429; отсюда `--pace`.
- **Автопроверка языка видит только половину класса.** `LanguagePurity` ловит украинские буквы
  (і/ї/є/ґ) и чужой скрипт, но НЕ украинское слово, написанное общими буквами («закрити рахунок»).
  Это ограничение цифр в отчёте, а не дефект прогона.

## Известные ограничения / отложенное

- Adapter Anthropic не проверен живым вызовом.
- Трек В (one-shot) — эксперимент; вывод по схеме пайплайна за архитектором.
- (carried) delta-sync `GET /sync?since=` полный, лог-ретеншн, two-device `client_seq` collision,
  retire `../backend`.
