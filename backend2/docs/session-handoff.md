## Не переигрывать молча (решения)

Полный список — `docs/DECISIONS.md`. Здесь только то, что легко переиграть по незнанию:

- **Справочник языков — по одному на репозиторий, с ОДИНАКОВЫМИ колонками**
  (`LanguageCatalog.php` / `language_endonyms.dart` / `languages.ts`). Не генерируется из одного
  источника намеренно: три рантайма выкатываются отдельно, а одинаковая форма строки превращает
  расхождение в однострочный дифф. В каждом репо тест держит состав по капабилити-матрице.
- **Где язык виден юзеру — эндоним** (п. 135). `nameRu`/`nameEn` лежат в справочниках для
  поверхностей, написанных О языке, а не НА нём.
- **Стиль форматтера mobile не настраивается, ширина настраивается.** `dart format` берёт стиль из
  языковой версии `pubspec.yaml`; вернуть короткий стиль можно только заморозив SDK. Ширина — в
  `analysis_options.yaml`.
- **`min_reps` на проводе `/sync` — намеренно** (маркер RENAME-DEFERRED в `ModeAdmission::toWire()`)
  при колонке `min_successful_reviews`. Обе стороны едут вместе на бампе контракта, не порознь.
- **Боевой стек генерации — v2** (ядро `v11.1`/`gpt-5.4`, механика `v13.1`/`gpt-4o-mini`);
  `GENERATION_STACK=v1` — временный откат на замороженный путь `v9`, судьба переключателя решается
  после перегенерации витрины (п. 131).
- **Пары языков произвольные** (п. 134). Ограничение «одна сторона всегда `en`» в
  `SupportedLanguages::supports()` — временное, к снятию в фазе A.
