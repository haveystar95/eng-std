# P2 — Plan Day (Scene) v0.4

Реестр: P2 day. Заменяет v0.3.1. Автор текста — архитектор. Ниже — тело промпта на
английском, затем контракт дня и список гейтов для кодовой сессии (в промпт не входят).

Дельта против v0.3.1: три массива phrases/words/chunks → полки сцены (hear/say/ask/words/
chunks/numbers) с ярусами; skill_ref обязателен у каждой карточки; пределы длины по kind;
стоп-список базового; запрет дублировать спасательный набор; узоры брака дней 1–2
(example = фраза дня, `___` в переводе, перевод без ключа, деревянные фразы) закрыты
явными правилами. Механика frame+filler, один вызов на попытку, повтор кодами без цитат,
P2R — без изменений.

## ТЕЛО ПРОМПТА (verbatim)

You write the content of ONE learning day for a language app. The day is a SCENE: one
real-life encounter the user must handle in {{target_lang}}. All context and translations
are in {{support_lang}}.

INPUT
- Goal: {{goal}}. Level: {{level}}. Target language: {{target_lang}}. Support language:
  {{support_lang}}.
{{target_lang_notes}}
{{support_lang_notes}}
- The scene (from the plan outline — title, intro, skills with ids, opening_lines,
  entities): {{scene}}
  The intro is already written; do not rewrite or repeat it.
- KNOWN units from previous days of this plan: {{known}}
  Never reintroduce them as cards. You may reuse them inside frames and examples — in NEW
  sentences only.
- Rescue kit of this plan (added by the server, trained daily): {{rescue_kit}}
  Never duplicate these phrases as cards.

OUTPUT — one JSON object, nothing else:
{
  "hear":    [ ... ],   // "you will hear": lines the other person says. Understanding only. Guide: 4–6.
  "say":     [ ... ],   // "you will answer": short replies the user will say. Guide: 4–6.
  "ask":     [ ... ],   // "you will ask": questions to clarify. Guide: 2–3.
  "words":   [ ... ],   // single words. Together with chunks: guide 6–8.
  "chunks":  [ ... ],   // set combinations of 2–4 words.
  "numbers": [ ... ]    // numbers in live scene context, listening only. Guide: 2–4.
}

EVERY ITEM CARRIES
- "kind": "line" for hear/say/ask, "word", "chunk", "number".
- "skill_ref": the id of ONE skill of the scene this card serves. Every card names its
  skill; every skill of the scene should get at least one card.
- "frame": the sentence with exactly one gap `___` where the key belongs. The gap exists
  ONLY in frame — never in translation, examples or anywhere else.
- "filler": the key — exactly the text of the card, as it stands in the gap. The server
  assembles the final sentence from frame + filler; you never output the assembled text.
- "translation": translation of the WHOLE assembled sentence into {{support_lang}}.
  Translate the finished sentence, not the frame: no `___` in it, and it must contain the
  translation of the key.

SHELF SPECIFICS
- hear: add "speaker": "role". These lines are for understanding only and may be up to 12
  words. Make them the lines this person will really face — use opening_lines as raw
  material, adapted to the scene.
- say / ask: 3–8 words when assembled. If a thought needs more, split it into two lines or
  move the load into a chunk — long utterances are trained by assembly, never as cards.
  Spoken register, natural word order, one thought per line. Lines of the day must be
  combinable with each other and with the day's words and chunks.
- words: at most 3 words. Also carry "example" — a NEW sentence in the scene's world using
  the word (never the word alone, never equal to any line of this day), "example_translation",
  and "image_api_prompt" — a concrete photographable moment. Only words get images.
- chunks: 2–4 words, set combinations (like "make an appointment"). Carry "example" /
  "example_translation" as words do; no image.
- numbers: "frame" is a natural line the other person says that contains the number, price,
  date or address; "filler" is the number expression as spoken; add "value" — the same
  number as digits (or ISO date). The user's task is listening.

CONTENT RULES
- Everything serves the scene: with today's shelves plus the rescue kit the user must be
  able to walk through this encounter.
- No basic vocabulary as cards: numbers, weekdays, family, colors, pronouns, be/have/go,
  "a little", "enough", "much", "again", "slowly" and the like are never cards. Numbers
  live only in "numbers".
- Proper names are never cards; use the scene's entities as fillers inside frames.
- For say/ask lines, prefer as the key (filler) a word or chunk from today's shelves — the
  gap is where today's vocabulary plugs into living speech. Never use as the key a word the
  day must not teach (basics, numbers, proper names).
- No clones: no two cards of the day assemble into the same text; no example equals a line
  of the day; nothing duplicates the rescue kit or a KNOWN unit.
- Prefer real, specific lines over formulas; formulas must stay a minority of the day.
- Across say/ask include at least one clarifying question and at least one repair move —
  but not the rescue-kit phrases themselves.
- If the support language requires a reading aid (see support notes), add
  "transliteration" to every hear/say/ask/word/chunk item: a practical reading of the
  assembled text in the support alphabet.
- Counts in this prompt are guidance, not law. Never pad with filler cards to hit a number.
- Answer with the JSON object only.

## КОНТРАКТ ДНЯ (поля, для кодовой сессии)

Полки: hear[], say[], ask[], words[], chunks[], numbers[].

Поле                  | Кто пишет | Примечание
----------------------|-----------|------------------------------------------------------
kind                  | P2        | line / word / chunk / number
tier                  | сервер    | speak (say, ask, words, chunks) / understand (hear, numbers) — выводится из полки, модель не задаёт
skill_ref             | P2        | id умения сцены
frame, filler         | P2        | `___` только в frame; text собирает сервер (как v0.3)
translation           | P2        | перевод собранной реплики целиком, содержит перевод ключа, без `___`
speaker               | P2        | только hear, "role"; роль — только на узнавание
example, example_translation | P2 | только words/chunks; новое предложение
image_api_prompt      | P2        | только words; у line/chunk/number картинок нет
value                 | P2        | только numbers: число цифрами / ISO-дата
transliteration       | P2        | при кириллическом языке поддержки, у всех полок кроме numbers
speaking_key          | сервер    | = filler (говорение по ключу, DECISIONS 218)
позиция/порядок       | сервер    | порядок сессии и полок — серверный, P2 не задаёт

Спасательный набор — конфиг языкового пакета, сервер вшивает в день 1 и в разогрев;
в контракт P2 он входит только как запретный список {{rescue_kit}}.

## ГЕЙТЫ v0.4 (валидатор, для кодовой сессии)

Лестница прежняя: карточное нарушение → P2R (v0.2, реплика чинится целиком); повтор дня
только при > ½ сломанных, с кодами + поле + номер карточки, БЕЗ цитат; один запуск = один
вызов; generation_attempts ≤ 2 (вызовы P2), repair_calls ≤ 2 — раздельно.

Карточные фатальные (→ P2R):
- card.gap_missing / card.gap_outside_frame — `___` нет в frame или встретился вне frame
- card.translation_has_gap — `___` в переводе (узор дня 2)
- card.translation_missing_key — перевод line без перевода ключа (гейт 219, действует)
- card.filler_not_card — filler ≠ текст карточки (фатально для en; прочие языки — по
  языковому пакету, warning plan_day_filler_mismatch)
- card.clone — собранный текст совпал с другой карточкой дня / спасательным набором / KNOWN
- card.example_is_a_term — пример равен карточке или любой фразе дня (узор дня 2)
- card.word_is_basic — стоп-список; фатально от уровня «Понимаю простое», ниже — warning
- card.kind_size — word > 3 слов; chunk вне 2–4; say/ask вне 3–8; hear > 12
- card.term_is_a_name — имя собственное карточкой (транслитерационный скелет; entities)
- card.translation_is_transliteration — перевод = транслитерация термина (равенство по скелету)
- card.skill_ref_invalid — skill_ref отсутствует или не из сцены
- card.number_value_mismatch — число в frame не сходится с value (только numbers)

Дневные фатальные:
- day.shelf_missing — полка hear / say / (words+chunks) отсутствует целиком
- > ½ карточек сломано → повтор дня (порог ½ не трогать — решение 01.09)

Warning со счётчиком (день живёт):
- day.size_out_of_range — полка вне ориентиров (4–6 / 4–6 / 2–3 / 6–8 / 2–4)
- day.formula_share — формул больше трети
- day.no_question / day.no_repair_move — нет уточняющего вопроса / починки
- day.skill_uncovered — умение сцены без единой карточки
- day.role_line_share, card.substitution_without_frame — как в v0.3.1
- scene.intro_repeated — модель пересказала вводку в карточках

Правило чисел действует: числа в прозе промпта — ориентир; фатально отбивается только
сломанный объект.

## ДЕЛЬТА v0.4.1 (наряд ENTRY-2, 03.09) — две правки архитектора, один бамп

Файл промпта: `plan_day.v0.4.1.md`. Реестр: строка **P2** с версией `plan_day.v0.4.1`.
Обе правки внесены в тело дословно; ниже они же, чтобы канон и код читались из одного места.

**1. Что такое связка — в SHELF SPECIFICS, к `chunks`:**

> A chunk is a self-sufficient piece of language that lives outside this one sentence (front desk,
> make an appointment, water pressure). NOT a chunk: a fragment cut off from its object (works
> for), an article plus a noun (the location), or a combination of basic words (see it). Translate
> the chunk's text exactly — never add words the text does not contain.

Две из трёх форм ловят гейты, третью держит только этот текст:

| форма | кто ловит |
|---|---|
| сочетание базовых слов («see it», живое «at night») | `card.chunk_is_basic` — ВСЕ слова связки в `BasicVocabulary` |
| артикль плюс существительное («the location», «an appointment») | `card.chunk_article_pair` — два слова, первое артикль |
| обрывок без своего объекта («works for») | **только промпт** |

Третья без механики сознательно (решение владельца 03.09): единственный стоп-список, который
поймал бы «works for», обязан держать `work`, а «works for me» — настоящая разговорная связка.
Ради неё гейт молчит, и предел назван вслух здесь и в докблоке `PlanDayValidator::checkChunks()`.

Ценой правки стало пополнение `en`-стоп-списка (артикли, базовые предлоги, `see`/`get`/`come` и
формы) — он ОБЩИЙ с `card.word_is_basic`, поэтому тест держит, что легальные слова дня
(«viewing», «heating») им не задеты.

**2. Баланс шага слуха — вход `{{balance}}` в INPUT:**

> - Balance (may be empty): {{balance}} — 'understanding' or 'speaking', the outcome of the user's
>   listening check.

и правило в CONTENT RULES:

> If balance is 'understanding', fill the hear shelf toward the upper end of its guide and say
> toward the lower end; if 'speaking' — the opposite. If balance is empty, ignore this rule.

Значение подставляет сервер из `ListeningDiagnostics::emphasis()`; пустая строка — обычный случай
(шаг необязателен), и промпт сам говорит, что тогда делать. Живой день с `understanding` вернул
`hear = 5`, `say = 4` (`docs/research/entry-2-run.md`).
