## Карточек на день по секциям (сверка с потолком 40)

Замер на фокусном дне 2 фикстурного плана, до прогона:

| секция | карточек |
|---|---|
| разогрев | 0 (у фикстурного плана спасатели дня 1 уже отвечены; на живом плане это 5) |
| слова и связки | 18 |
| знакомство с репликами | 2 |
| диалог сцены (день 2 + шов дня 1) | 30 |
| прогон сцены | 0 (сцена ещё не дозрела) |
| **всего** | **50**, присесты **34 + 16** |

Из 30 карточек диалога **15 — сборки** (по второму касанию на каждую из 15 реплик двух сцен). Потолок
присеста (40 при 20 минутах) не пробит: сервер режет посадку на два присеста по границе секции.
Полный день со всеми пятью секциями и дозревшим прогоном дал бы ≈ 5 + 18 + 2 + 30 + 6 = **61
карточку**, то есть два присеста по-прежнему, но второй — почти целиком разговор и прогон.

## Найдено живым прогоном и починено здесь же

1. **Ход прогона был вне ленты.** Оболочка разговора включалась только для секции `dialogue`, и
   ступень C оставалась голой карточкой: ни реплики собеседника перед ходом, ни выхода к спасателям.
   Починено: лентой играются ОБЕ секции — диалог и прогон.
2. **«Пропустить» в прогоне не писал ответа.** Кнопка шла по старому пути «отказ микрофона», который
   ничего не записывает, — и пропущенный ход выпадал из прогона совсем: итог показал «Прошёл сам 4 из
   4» на сцене из пяти ходов. Починено: в прогоне «Пропустить» пишет `speaking/again`, как и требует
   канон Ч.2.4.
3. **Под итогом прогона стояла строка диалога** — «дальше сборка», после того как человек уже сказал
   сцену голосом. Починено: у прогона своя строка.
4. **Сторож 15 с не даёт снять прогон автоматизацией.** Числа прогона переведены на env
   (`SCENE_RUN_LISTEN_SECONDS`, `SCENE_RUN_SKIP_AFTER_SECONDS`, `SCENE_RUN_FAST_SECONDS`) — они и так
   были конфигом по замыслу наряда; дефолты продуктовые и не изменились.

## Не покрыто прогоном

- **Ход спасателем.** Панель спасателей живёт в ленте разговора и берёт фразы из разогрева, а день,
  открытый вне очереди, разогрева не несёт — в этой посадке спасателей не было ни одного. Исход
  `rescued` остаётся покрытым кодом и серверным замком, но не снятым на устройстве.
- **Живой микрофон.** На симуляторе его нет; ходы отданы дев-дверью подстановки (`qa_tools`,
  только `is_qa` и только вне production).
