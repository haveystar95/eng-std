**§2. Типографика — одно правило.** `typeset(text, language)` в `lib/data/typography.dart`; списки — в
`lib/l10n/typography_words.dart`, рядом с эндонимами (кириллица вне `.arb` живёт только в `lib/l10n/` — страж
`no_cyrillic_outside_l10n_test`).
- **a) Правило.** ru, uk, be: U+00A0 после КАЖДОГО слова в одну-две буквы и после предлогов списка из трёх букв и
  «из-за» (ru — список наряда дословно; uk — «від, під, для, при, над, без, про, між, з-за, із-за» и короткие; be — «пад,
  для, пры, над, без, пра, між, з-за» и короткие). Остальные родные — после однобуквенных. Везде — перед «—». Слово —
  буквы без дефиса и апострофа перед ними («кто-то», «об'єм» слов «то», «єм» не содержат); регистр любой («Из-за», «В»).
- **b) Где.** Строки интерфейса — в самом `.arb` (у gen-l10n нет крючка на показ): `dart run tool/typeset_arb.dart`
  ставит правило тем же `typeset`, страж `nbsp_typography_test` держит КАЖДУЮ строку обоих файлов неподвижной точкой
  правила (раньше — только 107 ключей CLIENT-START). Поставлено: ru 366 строк, en 145. Родные тексты сервера — при
  показе, `context.nativeText(…)` / `NativeTypesetter` (`lib/ui/native_text.dart`) по языку плана: `NativeLanguageScope`

  событие, название плана, «просрочено», роли, цели дня, заголовок разговора, подсказка разговора, строки урока и их
  переводы, вопросы проверок, варианты-переводы, переводы слов/фраз/реплик окна дня, причина судьи, набор выживания,
  уведомления и баннеры. Строки, которые сервер СОБИРАЕТ из своих пакетов (`summary`, `until_phrase`, `highlights`,
  подписи слотов), ставятся по их языку: ru/uk/en, для прочих родных английский (plan-api, LANG-1).
  **Не трогается язык цели**: каркасы, реплики, слова, варианты цели, распознанная речь, чтения `pronunciation_native`
  (их читают вслух), ключи кэша звука и подсказки распознавателю. Граница — поле контракта, данные в моделях сырые:

`GATES_DRY_RUN=1` печатает дерево и команды. Проверено: 13 форм команды всухую (`cd … && git add && git commit`,
`git -C`, относительный `cd`, накопленные `-C`, `~`, `SKIP_GATES=1` на коммите, подоболочка, многострочная команда,
`cd` обратно в main, `--work-tree=`, `commit --dry-run` — не коммит) и настоящий прогон на временном worktree: deptrac 0,

пропустил). Первая попытка — цепочкой `git add … && git commit` — была остановлена старым хуком: до `add` он берёт все

коммит сделан отдельными `git add` и `git commit`. **Хук в `main` станет новым только после слияния ветки.**

## Отступления от буквы (п. 5)

1. **«PackageInfo»** — версия и так читалась с устройства своим каналом `app_info` (те же два ключа Info.plist, что
   читает `package_info_plus`); плагин ради этого не добавлял. Константой «1.0.0 (22)» был только тестовый харнесс.
2. **Двухбуквенные слова ru/uk/be связываются все**, не только списка: канон «на те дни» требует «те» (не предлог).
   Под правило попадают и «мы», «он», «ИИ». Список наряда хранится дословно — его вклад сверх длины это «под, для, при,
   над, без, про, из-за».
3. **Строки `.arb` несут правило в исходнике**, а не ставятся при показе: у gen-l10n нет крючка на показ; правило и
   его функция — одни (`typeset`), страж держит все строки.
4. **Строки сервера из пакетов** (`summary`, `until_phrase`, `highlights`, подписи слотов) ставятся по языку пакета
   (ru/uk/en, иначе en), а не по родному: по контракту они на нём и приходят.
5. **Цель ученика в строках-итогах входа** (22-2…22-4, «Цель · …») и в шапке плана без названия ставится при показе —
   это тоже родной текст на экране; уходит на сервер она нетронутой.
6. **ICU-ветка `planTalkEntryRuleRescue`** переписана: «и {…female{она повторит} other{он повторит}} проще» — слово,
   которое держит «он», внутри ветки, иначе правило в шаблоне его не видит («он / повторит»). Страж ловит такие ветки.
7. **Чтения** (`pronunciation_native`) не ставятся: их читают вслух.
8. **Списки uk и be** составлены мной «той же формы» — наряд их не перечислил.
9. **Старый тренажёр** (коллекции, поиск, карточка слова, триаж, слово дня) — переводы слов не ставятся, только его
   строки `.arb`. Наряд перечисляет тексты плана; переводы старого тренажёра — данные зеркала (варианты ответа, ключи
   сравнения дистракторов), это отдельный проход по ~25 экранам. Вопрос 2.
10. **Хук** сверх «проверять дерево worktree» сам даёт worktree `vendor/`/`.env` и отдельную базу — без этого проверка
    дерева worktree не работает и мешает соседнему прогону.
